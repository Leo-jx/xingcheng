星城穿搭

四季衣橱 · 男女皆有
芽芽的四季穿搭指南

长沙四季分明：春天潮、夏天晒、秋天爽、冬天湿冷入骨。小戏芽请来两位会穿的长沙年轻人，为你示范女生版与男生版的时尚出游搭配——跟着穿，不晒黑、不冻着、不摔跤~

女生版 · 春日穿搭

  • 薄风衣 / 针织开衫早晚披上，中午塞包里
  • 长裙或阔腿裤棉麻料透气，下雨也快干
  • 防水小白鞋石板路多，鞋底要防滑
  • 透明雨伞 + 草编包春雨说来就来，顺手还出片

男生版 · 春日穿搭

  • 连帽卫衣 + 轻薄夹克洋葱式穿法，冷热都接得住
  • 卡其休闲裤卷个裤脚更有味道
  • 防水运动鞋岳麓山雨后石阶滑，别穿平底板鞋
  • 帆布包装伞、装外套、装橙子
芽芽提醒：长沙春雨连绵还有回南天，衣物两天都晾不干——多备一双袜子，住宿时问问有没有烘干功能，比什么穿搭都实在。

女生版 · 夏日穿搭

  • 棉麻连衣裙 / 吊带 + 轻纱裙透气不闷汗
  • 草编遮阳帽 + 防晒冰袖暴晒天出门刚需
  • 凉鞋 / 透气运动鞋逛夜市走两万步也不累
  • 链条小包 + 墨镜解放双手，凹造型利器

男生版 · 夏日穿搭

  • 透气短袖T恤纯色更显气色，深色耐脏
  • 宽松短裤湖南的夏天，能短就短
  • 渔夫帽 + 蒲扇防晒降温两件套
  • 凉鞋或网面鞋爬岳麓山建议换成运动鞋
芽芽提醒：白天 38℃ 暴晒，商场冷气又开得很猛——包里塞件薄防晒衣；傍晚去解放西、扬帆夜市和湘江边吹晚风，才是夏天正确的打开方式。

女生版 · 秋日穿搭

  • 茜橙针织衫秋天的颜色配满城桂花
  • 杏色风衣湘江边拍照的战袍
  • 百褶长裙 + 短靴爱晚亭红叶季正合适
  • 披肩或薄围巾山里早晚温差近 10℃

男生版 · 秋日穿搭

  • 浅灰毛衣 / 卫衣单穿或叠穿都好看
  • 驼色夹克和岳麓山的银杏一个色系
  • 卡其长裤 + 小白鞋徒步逛街两不误
  • 小相机挂胸前11 月中下旬来拍红叶最佳
芽芽提醒：10–11 月是长沙最舒服的季节，橘子洲头芦花、岳麓山红叶都在路上——但早晚偏凉，风衣别急着收进箱子。

女生版 · 冬日穿搭

  • 朱红厚呢大衣 / 斗篷雪天里最亮眼的一抹中国红
  • 米白大围巾 + 毛绒手笼芽芽同款，暖到指尖
  • 加绒长裙 + 雪地靴风度温度我全都要
  • 暖宝宝贴后腰，谁贴谁知道

男生版 · 冬日穿搭

  • 厚羽绒服湿冷面前，颜值让位给保暖
  • 加绒裤秋裤是长沙冬天的入门门票
  • 保暖靴 + 厚袜石板路冷气从脚底冒上来
  • 手套与护耳江风一吹，耳朵最先举手投降
芽芽提醒：长沙冬天是"魔法攻击"——0~8℃ 的湿冷没有暖气加持，体感比北方的干冷还钻骨头。进屋先捧一碗热米粉，出门揣一袋糖油粑粑，手炉才捧得稳。
伞常备长沙的雨说下就下 舒服的鞋日均两万步不是传说 洋葱式穿法室内外温差随时切换 拍照穿暖色青瓦白墙前朱红最上镜 夜市别穿新白鞋糖油酱汁危机预警
